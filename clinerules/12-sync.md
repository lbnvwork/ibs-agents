## Синхронизация окружения («синхронизируйся»)

По команде «синхронизируйся» (или «обнови окружение» / «перечитай контекст») — вызови скилл `sync-env`:
1. Обновить код: `git fetch origin && git pull origin develop` (в своей ветке — merge develop).
2. Обновить docs: `cd docs && git pull origin main`.
3. Перечитать правила `.clinerules/` (свой `00-role.md` + `20-workflow.md`).
4. Перечитать план/статус: `03-Задачи/Планы спринтов/Детальный план спринтов.md`, `Текущий спринт.md`, `03-Задачи/Канбан.md`, `09-Служебное/Оперативная сводка.md`.
5. Перечитать регламенты `09-Служебное/Регламенты/`.
6. Обновить конспект `.cline/context.md` (5–10 строк: текущая задача, статус, что дальше).
